Virgil is installed

Select Virgil Virtual Soundcard in System Settings > Sound or in your audio app.

Set the network interface and flows in
/Library/Application Support/Virgil/virgil.conf
then restart the service:
sudo launchctl kickstart -k system/org.virgil.virgild

Status: virgild --status   Log: /Library/Logs/Virgil/virgild.log
Uninstall: sudo "/Library/Application Support/Virgil/uninstall.sh"
