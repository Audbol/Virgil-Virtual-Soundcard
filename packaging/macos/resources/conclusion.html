DSV is installed

Select DSV Virtual Soundcard in System Settings > Sound or in your audio app.

Set the network interface and flows in
/Library/Application Support/DSV/dsv.conf
then restart the service:
sudo launchctl kickstart -k system/org.dsv.dsvd

Status: dsvd --status   Log: /Library/Logs/DSV/dsvd.log
Uninstall: sudo "/Library/Application Support/DSV/uninstall.sh"
