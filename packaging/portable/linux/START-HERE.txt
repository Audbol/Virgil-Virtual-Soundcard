Virgil Virtual Soundcard - portable for Linux (x86_64, glibc 2.35+)
===============================================================

Dante virtual soundcard with an ALSA device: the computer shows up in Dante
Controller as a Dante device named "Virgil"; route it there.

1. ./setup-alsa.sh
   Adds the "virgil" ALSA device to ~/.asoundrc, pointing at this folder.

2. ./virgil-control
   Starts virgild from this folder and opens the control panel in your browser.
   For PTP (ports 319/320) and real-time priority, run virgild with
   privileges instead:  sudo ./virgild -c virgil.conf

3. In Dante Controller, subscribe Virgil's channels.

4. Use ALSA device "virgil" (e.g. aplay -D virgil, jackd -d alsa -d virgil_hw -p 64).

Settings: virgil.conf in this folder. Log: virgild.log.
For a system service that starts at boot, install the .deb / .rpm instead.
