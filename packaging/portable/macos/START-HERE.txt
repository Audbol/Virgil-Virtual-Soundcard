Virgil Virtual Soundcard - portable for macOS 11+ (Apple silicon and Intel)
=======================================================================

Virtual soundcard for Dante networks with a Core Audio device: the Mac appears in Dante
Controller as a device named "Virgil"; route it there.

This download is not notarised. Before the first start, open Terminal in
this folder and run:      xattr -dr com.apple.quarantine .

1. Double-click "install-driver.command" (asks for your password) to add the
   "Virgil Virtual Soundcard" Core Audio device. Core Audio restarts once.

2. Double-click "Virgil Control". It starts virgild from this folder and opens the
   control panel in your browser.

3. In Dante Controller, subscribe Virgil's channels.

4. Pick "Virgil Virtual Soundcard" in System Settings > Sound or in your app.

Settings: virgil.conf in this folder. Log: virgild.log.
Run as a normal user, virgild cannot use PTP ports and real-time priority as
fully as the installed version; for an always-on setup that starts at boot,
use the installer Virgil-<version>-macos.pkg instead.

Remove the driver: sudo rm -rf /Library/Audio/Plug-Ins/HAL/VirgilAudio.driver
and then: sudo killall coreaudiod
